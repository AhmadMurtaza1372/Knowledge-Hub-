## Knowledge Hub

A book discovery platform integrating external APIs for real-time search. 

This repository archives my foundational web project, originally developed during my Diploma in Software Engineering (DISE) in 2023/24 at ILS Srinagar. It was built to master the fundamentals of frontend-backend communication and external API integration.

## Tech Stack
*   **Frontend:** React.js
*   **Backend:** Node.js
*   **Storage:** LocalStorage (Client-side state persistence)
*   **External Data:** Google Books API

## Core Features
*   **User Authentication:** Basic login flow establishing user sessions.
*   **Live Search:** Direct integration with the Google Books API to fetch and render book data dynamically based on user queries.
